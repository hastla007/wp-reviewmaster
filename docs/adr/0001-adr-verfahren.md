# 0001 – ADR-Verfahren einführen

- **Status:** angenommen
- **Datum:** 2026-11-16
- **Betrifft:** Sonstiges
- **Tasks:** RC-031

## Kontext
Konzept und TODO verlangen, dass Änderungen an Schema, Verträgen, Lizenzrechten und Anbieterzugängen mit Datum und Grund nachvollziehbar sind.

## Entscheidung
ADRs als Markdown unter `docs/adr/`, fortlaufend nummeriert, Index in `README.md`. Jede PR, die Schema, öffentliche Verträge oder Entitlements ändert, enthält eine ADR.

## Folgen
Entscheidungen aus den M0/M1-Entwürfen werden als ADR „vorgeschlagen“ erfasst und nach Freigabe auf „angenommen“ gesetzt.
